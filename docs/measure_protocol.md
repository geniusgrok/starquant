## 输入与身份

三份 BTC 冻结输入的字节数、SHA 和原始 zip 来源见 [数据说明](btc_account.md#数据)；重建资产输入 SHA 见 [PROJECT_STATE.md](../PROJECT_STATE.md#当前输入和验证)。三份正式报告还记录期末 USDT 和期末估值用 USD/CNY；USDT/USD 平价与 0.35% 假设兑换费不是可成交 CNY/USDT 报价。`provenance.files_sha256` 标识影响结果的内核、估值、配置、数据和研究代码；`git_head` 是运行时源码提交，`git_dirty` 只检查代码/配置的改动，不把报告 JSON 自己计为代码改变。每次运行写唯一 `run_id` 的本地 `reports/runs/` 副本，输入及路径验证通过才替换正式 JSON，失败写 `.unverified.json`。旧的已验证泛化指针已移除，不能和本版输入混用。

标记价与成交价、分钟内顺序、历史真实维持保证金档位、跳空深度及实盘成交无法由 OHLC 证明；真实时钟停机只有交易所已确认的保护继续执行。模型的 20 倍逐仓保证金设置、名义仓位/权益和止损风险是不同数量，不足以与其他项目的利润直接排名。
