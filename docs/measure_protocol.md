执行 `python -m btc_perp robustness`，详情见 [报告](../reports/btc_account_robustness.json)。它对同一因果回放应用固定成本/参数变化，不替换发布参数：

资金费两行是人为选定的统一费率情景，**不是**官方费率的数学上下界，也不验证 2026-09-01 00:00 的实际结算。54 个单参数 ±5%/±10% 邻居里 14 个跌破一半峰值或以回撤锁结束。2020 年末权益约 154,748 元，从这一点到样本末段的年化约 54.17%；全窗表现明显依赖开头一年。

执行 `python scripts/assets.py` 和 `python -m btc_perp generalization` 复现 [其他行情报告](../reports/btc_account_generalization.json)。ETH、SOL、2017–2019 BTC 现货的基准分别约 +1.68%、−2.61%、−1.58% 年化且均以回撤锁结束；候选模型及 36 点网格只做研究，不接入前向账户。其他币种 2026-09 的官方资金费也缺失并按零计，报告逐行情写出该事实；现货没有资金费。由于 BTC 2020–2026 已用于选参数，这些结果也不能洗成 BTC 的新样本外证据。

## 输入与身份

三份 BTC 冻结输入的字节数、SHA 和原始 zip 来源见 [数据说明](btc_account.md#数据)。正式报告还记录期末 USDT 和期末估值用 USD/CNY；USDT/USD 平价与 0.35% 假设兑换费不是可成交 CNY/USDT 报价。`provenance.files_sha256` 标识影响结果的内核、估值、配置、数据和研究代码；`git_head` 是运行时源码提交，`git_dirty` 只检查代码/配置的改动，不把报告 JSON 自己计为代码改变。每次运行写唯一 `run_id` 的本地 `reports/runs/` 副本，已核验完整运行才替换当前 JSON，否则写 `.unverified.json`。

标记价与成交价、分钟内顺序、历史真实维持保证金档位、跳空深度及实盘成交无法由 OHLC 证明；真实时钟停机只有交易所已确认的保护继续执行。模型的 20 倍逐仓保证金设置、名义仓位/权益和止损风险是不同数量，不足以与其他项目的利润直接排名。
