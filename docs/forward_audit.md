## 研究与经济事实

| 附件项 | 处理与结论 |
| --- | --- |
| SR1 新移动止损在同分钟提前生效 | 修回放内核：本分钟只运行此前止损，收盘更新从下一分钟生效。旧止损命中与新止损不命中两个构造验证；四份当前经济报告统一重跑。 |
| SR2 输入校验不完整 | 正式窗口、分钟对齐/连续、OHLCV 有限及逻辑、资金费、FX 边界和有效性均核验；泛化也拒绝缺永续资金费和坏行情，不再默默填零并标已核验。 |
| SR3 配置与内核资金/成本漂移 | `config.py` 在运行时逐项核对冻结的 `costs.py` 值；维持保证金档位从同一个 `MARGIN_BRACKETS` 定义读取。 |
| SR4 报告口径与身份 | 区分诊断 `passed`、150% `economic_pass`、数据结构验证、回放走完和真实执行闭环；报告记录输入及影响研究的源码 SHA。当前 150% 未达，真实执行未闭环。 |
| SR5 成交/标记价与分钟路径 | 仍用成交 OHLC 代理标记价，分钟四点先后和历史固定档位。没有可靠的同期标记价/盘口回放，不宣称已消除模型偏差；止损额外滑点情景如实报告。 |
| SR6 资金费缺口 | 7,305 官方、56 溢价估算、1 缺失补零并列时间；另做 57 个非官方槽位统一设为 ±0.3% 的固定情景，不能称官方上下界。未伪造 2026-09-01 00:00 官方值。 |
| SR7 人民币估值 | 报告同时给期末 USDT 和 CNY、期末 FX；USDT/USD 平价、前一已公布 Frankfurter 中间价及 0.35% 假设兑换费明确标注，非实际可交易报价。 |
| SR8 成本/参数敏感性 | 额外 0.1% 止损滑点令因果年化约 41.55%、最低比值约 0.475 并锁住；54 个邻居 14 个失败/锁住；去掉 2020 年之后约 54.17%。不把默认点视为稳健收益估计。 |
| SR9 研究与运行日程 | 706,752 段 300 秒会话连续衔接，不代表偶尔启动；真实 `run` 连续轮询，停机期间动态规则不执行，旧随机跳过会话结果不再当成本版数据。 |
| SR10 跨项目比较 | 不从不同历史版本和不同执行模型挑最高数字排名；20 倍只是保证金设置。当前没有统一日程、mark/资金费、敞口与成交数据支持横向收益排名。 |

当前结果：同根收盘 `measure` 期末 **1,830,997.66 元、117.16%**，因果 `causal` **1,839,663.45 元、117.31%**，最低比值分别 **0.526、0.528**，均为 **57 多 / 35 空 / 80 止损**。正式 100% 诊断线过，150% 目标未达。旧 202 万元与 120% 数字属于旧的分钟内提前收紧止损模型。输入哈希与分年、压力、泛化细节见 [measure_protocol.md](measure_protocol.md) 和报告 JSON。

## 运维边界

| 附件项 | 当前结论 |
| --- | --- |
| SO1 长运行每日备份 | 每轮检查 UTC 日期，用 SQLite online backup 原子写入每日副本并保留七份；失败可见，跨盘副本仍靠人工。 |
| SO2 历史恢复窗口 | 留下成交及流水上次确认时间；超过近七日或最近 1000 条不能覆盖游标则冻结。接管可管理当下仓位，却不能伪造缺失历史，重置命令不能清缺口。 |
| SO3 入场与保护非原子 | 保留预检、持久身份、ACK 丢失按原 ID 查询、失败明确未覆盖和已归属仓位的只减仓路径。无远端绝对保护保证。 |
| SO4 资金/日损上限语义 | 只阻断新增风险，不保证最大累计亏损；手续费、资金费和划转以钱包权益/收入流水反映，划转冻结，回撤峰值不由接管重置。 |
| SO5 跨项目同账户 | 使用边界限定一个项目管理一个账户，交接须核对仓位与 close-all 保护；本地锁不保证 Coinquant 互斥。 |
| SO6 辅助权限故障 | 生产 `run` 新风险须权限完整；已确认 UID 的 `stop`/`flatten` 可走降险，身份不明所有账户写入拒绝。 |
| SO7 `isolatedMargin` 疑点 | 官方字段与本地解析核对后，快照一致性键改用仓位数量、成本、`isolatedWallet`、模式/杠杆；价格自然浮动不应造成状态撕裂，钱包/仓位变化仍需重读。此为字段语义下的保守推断，未有真实脱敏响应验收。 |
| SO8 协议组合 | 新旧同向 close-all、父子真实回包未远端核验；模拟只证明拒单/ACK 丢失时保留保护及未完成结论。 |
| SO9 平台依赖 | 固定 Linux/Python 3.12/`requirements.lock`；原生 Windows、多机器并发未宣称支持。 |

可选 SS1–SS5 中，主循环不再启动没有控制职责的 WebSocket 维护；订单门禁、归属和完成结论沿用现有函数；当前文档以本文件与 `PROJECT_STATE.md` 为入口。保留单个 CI 离线门槛和研究候选模块，不新建交易平台或让可选简化阻断安全修复。
