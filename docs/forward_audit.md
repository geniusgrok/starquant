## 剩余风险

- 没有 5 秒成交带。分钟内部仍是开高低收四点。前向权益路径比历史测量更粗。
- 进程不在时，通道出场和一半峰值平仓不会执行。停机保护只有最后一次确认的止损和灾备止盈。
- 维护保证金率仍是回放里的一张表，前向强平距离来自当次快照，两者不是同一条数据。
- 用户流字段和 `/private/ws` 路径对照的是 binance SDK 3.6.0、一份 2025-12-11 的公开报文，以及 unicorn-binance-websocket-api 对 2026-04-23 变更的实现。官方 HTML 页面在本机仍被脚本墙挡住。真实 Demo 套接字没有连上。
- 本机地区限制和缺少密钥，使官方 Demo 与生产的只读核对都没有发生。
- 资金费 2026-09-01 00:00 UTC 未验证，2026-09 其余槽位是溢价估算。
- 工程上可以启动，不等于 150% 年化或回撤低于 50% 已经达到。一个月 Demo 盈利也不能外推。
